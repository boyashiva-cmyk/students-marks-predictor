# AI/ML Student Performance Predictor

## 1. Project Overview
This project is a Command-Line Interface (CLI) based Machine Learning application. It predicts a student's final marks based on their daily study hours and previous test scores using a Linear Regression model. 

## 2. Dependency Installation
```bash
pip install -r requirements.txt
```

## 3. Execution Instructions (How to Run)
1. Open terminal/command prompt.
2. Run:
   ```bash
   python main.py
   ```
3. Follow the interactive prompts to enter study hours and previous scores.
